# Terrace

> Plataforma de Engenharia de Dados para processamento e análise de dados de eventos de futebol utilizando o [StatsBomb Open Data](https://www.hudl.com/en_gb/products/statsbomb)

Projeto desenvolvido em Python com o objetivo de construir uma plataforma completa de dados, desde a ingestão de dados brutos até a disponibilização de informações analíticas

## Primeiros Passos

Clone o repositório:

```bash
git clone https://github.com/RodriguesGS/Terrace.git
```

Acesse o diretório do projeto:

```bash
cd terrace
```

Instale as dependências:

```bash
uv sync
```
